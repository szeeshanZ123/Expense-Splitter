# Expense Splitter

A simple **C++ Data Structures project** that helps manage and split shared expenses between multiple people.

## Features

* Add people and expenses
* Calculate total and equal expenses
* Search and sort people
* Display expense summary
* Generate settlement transactions
* Demonstrates Array, Linked List, Stack and Queue

## Technologies

* C++
* Turbo C++ Compatible

## Data Structures Used

**Array • Linked List • Stack • Queue**
